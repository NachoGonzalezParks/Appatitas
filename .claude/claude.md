# APPATITAS SDD RULES

Este proyecto sigue Software Design Document Driven Development.

La única fuente de verdad es:

docs/SDD_MASTER.md

Antes de cualquier implementación:

1. Leer requisitos relacionados.
2. Identificar historia de usuario.
3. Identificar reglas de negocio.
4. Identificar tablas afectadas.
5. Crear plan técnico.
6. Validar contra SDD.
7. Implementar.

Prohibido:

- Inventar funcionalidades.
- Crear endpoints no especificados.
- Crear tablas fuera del diseño.
- Modificar modelos sin actualizar documentación.
- Asumir reglas de negocio.

Si falta información:

DETENERSE y solicitar aclaración.
